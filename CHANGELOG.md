# Changelog

## 0.0.1 — 2026-10-22

Initial public release.

- Namespaces for systemd services and Docker containers, persisted in SQLite.
- Service discovery, live state, listeners/ports, cgroup CPU/RAM and uptime.
- Read-only Nginx proxy/domain association.
- Opt-in lifecycle controls, log and environment inspection, guarded systemd unit editor.
- Create-service wizard (.NET, Node, registry image, local Dockerfile).
- Separate `/app-spaces` workspace tab and Proxy Project shortcut.
